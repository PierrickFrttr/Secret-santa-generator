# 🎅 Secret Santa

Générateur de Secret Santa en un seul fichier HTML, ambiance Noël.

**En ligne :** https://pierrickfrttr.github.io/Secret-santa-generator/

## Fonctionnement
1. L'organisateur saisit les prénoms (et, en option, l'événement, le budget, la date).
2. Il lance le tirage et partage **un seul lien**.
3. Chaque participant clique sur son prénom, confirme, et ouvre son paquet pour découvrir à qui il offre un cadeau.

## Règles garanties
- Personne ne se tire soi-même, chaque prénom n'est tiré qu'une seule fois (un seul grand cercle, algorithme de Sattolo).
- Le tirage est fait une seule fois et scellé (chiffré) dans le lien : retenter donne toujours le même résultat.
- L'appareil retient le prénom choisi : impossible d'en choisir un autre ensuite.

Aucun compte, aucun serveur, aucune base de données : tout se passe dans le navigateur.
